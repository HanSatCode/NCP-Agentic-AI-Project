# 디자인 검토 (DESIGN.md 기준)

기준은 저장소의 `DESIGN.md`다. 기능·배치 규칙은 `CLAUDE.md`(S-00~S-04, 배지, 안내 문구)를 따른다. 이 스킬은 규칙을 새로 만들지 않는다. 두 문서에 없는 것은 "기준 없음"으로 적고 물어본다.

## 1. 범위 정하기
- 지정이 없으면 `git diff --name-only`로 바뀐 화면 파일(`app/**/*.tsx`, `app/*.css`)만 본다
- "전체"라고 하면 소개(`app/Intro.tsx`, `app/IntroDemo.tsx`, `app/intro.css`)와 정리 도구(`app/FileVersionApp.tsx`, `app/globals.css`)를 모두 본다

## 2. 코드로 보는 것
| 항목 | DESIGN.md | 어떻게 확인 |
|---|---|---|
| 주 버튼 하나 | 1장 원칙 1 | 한 영역(`section`, 하단바, 카드) 안에 `btn primary`가 둘 이상인지 |
| 색은 토큰으로 | 3장 | 새 CSS에 색 값이 직접 들어갔는지. 토큰(`var(--brand)` 등)이 있으면 그걸 씀 |
| 색의 뜻 | 1장 원칙 2 | 파랑 = 할 일·선택, 초록 = 추천·완료·안전, 노랑 = 확인 필요, 회색 = 빠짐, 빨강 = 오류. 뜻이 뒤바뀌지 않았는지 |
| 배지 4개만 | CLAUDE.md 배지 표 | 최신 후보·확인 필요·중복·직접 선택 말고 새 배지가 생겼는지 |
| 글자 크기 | 4장 표 | 정리 도구는 고정 크기, 소개는 `clamp` |

| CSS 괄호 | — | `{`와 `}` 개수가 같은지 (닫히지 않은 `@media` 안에 규칙이 갇히면 그 폭에서만 적용됨) |

### 움직임 (7장)
- 곡선은 `var(--ease-out)` 하나, 시간은 7장 표의 값
- **같은 때 바뀌는 것은 같은 시간에.** 목록 위치(`--i`)로 지연을 주는 건 처음 나타날 때만
- **처음 나타나기는 한 번만.** 상태 클래스(`is-on` 등)가 붙고 떨어질 때 `animation`이 바뀌면 처음 애니메이션이 다시 돈다 → 처음 애니메이션은 안쪽 요소에 건다
- `animation-fill-mode: both` + 지연이 있으면 지연 동안 숨는다. 다시 돌 수 있는 곳에는 쓰지 않는다
- JS 타이머 애니메이션(타이핑·자동 넘김·전환)은 `prefers-reduced-motion: reduce`에서 시작하지 않는다. CSS는 `globals.css`가 1ms로 줄인다

### 줄바꿈 (8장)
- 파일 이름: 예시 카드는 `nowrap` + 넘치면 `…`, 문장 속은 띄어쓰기를 줄바꿈 없는 공백으로
- 바뀌는 글자(타이핑)는 따로 한 줄이거나 `nowrap` 묶음 안에. 가장 긴 이름("이거_건들지마", "교수님_피드백_반영")으로 확인
- 뜻이 한 덩어리인 어구는 `intro-nowrap`으로 묶기
- 제목은 `balance`, 설명은 `pretty`가 걸려 있는지

### 접근성 (10장)
- 누르는 것에 키보드 초점(`tabIndex`, `:focus-visible` 3px `--ring`)
- 움직이는 글자는 화면 읽기에 고정 문장 (`aria-label`, `sr-only` + `aria-hidden`)
- 색만으로 뜻을 전하지 않음 (글자·굵기·줄 긋기를 같이)

## 3. 화면으로 보는 것
- `/screen-capture`로 1280 · 1100 · 960 · 640px를 찍는다. 움직임이 끝난 상태는 동작 줄이기 캡처로 본다
- 캡처를 직접 열어 본 것만 "확인"이라고 쓴다. 움직이는 모습은 캡처로 확인할 수 없으므로 "브라우저에서 확인 필요"로 남긴다

## 4. 보고
| 심각도 | 뜻 |
|---|---|
| 고칠 것 | DESIGN.md·CLAUDE.md와 다름 (예: 주 버튼 둘, 배지 다섯 번째, 파일 이름이 중간에서 끊김) |
| 다듬을 것 | 기준 안이지만 어색함 (예: 한 단어만 남은 줄) |
| 기준 없음 | 두 문서에 없음 → 물어보거나 DESIGN.md에 더할지 제안 |

- 항목마다 `파일:줄`과 고칠 방법 한 줄. 고치기는 승인받은 뒤에 한다 (CLAUDE.md 작업 규칙)
- 고친 값이 DESIGN.md의 숫자와 달라지면 DESIGN.md도 같이 고친다 (D-53)
